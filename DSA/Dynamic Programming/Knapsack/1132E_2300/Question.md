# 1132E - Knapsack

- Platform: Codeforces
- Problem Link: https://codeforces.com/problemset/problem/1132/E
- Rating: 2300

You are given counts of items with weights `1` to `8`, and each item’s value equals its weight. For a knapsack capacity `W`, find the maximum total weight/value that can be achieved without exceeding `W`.
