# 161D - Distance in Tree

- Platform: Codeforces
- Problem Link: https://codeforces.com/problemset/problem/161/D
- Rating: 1800

Given a tree with `n` vertices and an integer `k`, count the number of unordered pairs of vertices `(u, v)` such that the shortest path distance between them is exactly `k`.

Input provides `n`, `k`, and `n-1` edges of the tree.
